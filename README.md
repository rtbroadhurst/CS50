This repository contains my solutions and final project from [Harvard's CS50x: Introduction to Computer Science](https://cs50.harvard.edu/x/).

The course covers core computer science concepts including algorithms, data structures, memory, databases, web development, and programming in C, Python, SQL, JavaScript, and Flask. This repository serves as both a personal learning log and a showcase of the technical skills developed throughout the course.
